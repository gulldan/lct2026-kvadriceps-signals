# trend-sources

Один образ, четыре роли по `SOURCE_KIND`: `patents` (`patent-collector`), `cn-patents`
(`cn-patent-collector`), `web` (`web-collector`) и `arxiv` (`arxiv-gateway`). Данные и каталоги
у ролей раздельные, наружу порты не публикуются. Кто их читает — в
[docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md); импорт записей в конвейер документов — в
[source-harvester](../source-harvester/README.md).

## Настройка

`SOURCE_CONFIG` — JSON до 128 KiB, заменяет встроенные значения. В Compose это
[infra/trend-sources.json](../../infra/trend-sources.json): панель источников, домены и бюджеты
живут там. [source-config.example.json](source-config.example.json) — короткий пример со
включёнными EP и CN.

| Поле                | Пределы  | Смысл                                                                  |
| ------------------- | -------- | ---------------------------------------------------------------------- |
| `history_months`    | 1..36    | глубина истории в месяцах кроме текущего                               |
| `request_budget`    | 1..20000 | запросов за проход                                                     |
| `render_budget`     | 0..2000  | рендеров за проход; 0 — без предела, если задан `RENDER_URL`           |
| `ep_documents`      | 0..5000  | документов EP за проход; 0 выключает источник                          |
| `ep_fair_use_bytes` | до 9 ГиБ | недельный объём EPS; 0 — 9 ГиБ, запас от лимита провайдера             |
| `ops_documents`     | 0..20000 | записей EPO OPS за проход; 0 выключает                                 |
| `ru_documents`      | 0..5000  | записей Роспатента за проход; 0 выключает                              |
| `cn_documents`      | 0..5000  | новых CN-документов за проход; 0 выключает                             |
| `patent_terms`      | до 64    | термины отбора патентов; пусто — проверять каждый документ             |
| `web`               | до 320   | источники: уникальное `name`, HTTPS `url`, `kind`, `industry`, `pages`, необязательный `genre` |
| `allowed_domains`   | до 320   | панель доменов; пусто — хосты самих источников                         |

`kind` у веб-источника: `feed` (RSS, Atom и JSON Feed), `rss`, `wordpress`, `url`, `urls` (до
500 адресов), `sitemap`, `cncf`, `techport`, `hf_papers`, `hf_models`, `bing_news`,
`europe_pmc`, `crossref`, `clinical_trials`, `biorxiv`, `datacite`, `zenodo`, `figshare`, `biostudies`. Лента
обогащает за проход не больше `pages` статей (по умолчанию 20), остальное сохраняется
метаданными с курсором.

У научных API `pages` ограничивает страницы ответа, по умолчанию две: до 100 записей на
страницу (Zenodo — 25, bioRxiv задаёт размер сам). Каждому домену выделен отдельный запрос;
30 запросов по медицине, сельскому хозяйству, климату, энергетике, материалам, экономике,
образованию и другим темам выполняются до общей панели новостей. Добавлены десять
предметных лент Nature и PLOS.

Научная запись передаёт `doi`, `doi_aliases`, `genre` (`article`, `preprint`, `clinical_trial`,
`dataset`, `software`), отрасль, дату публикации и происхождение. Версии DOI объединяются.
Аннотации сохраняются как `abstract_only`; отсутствие аннотации — `metadata_only`. Даты
обновления и регистрации DOI не подменяют публикацию. Год без точного дня исключается из
временного ряда. Обход API ограничен бюджетом и не заявляет полного архива; курсор в
покрытии показывает место остановки, следующий проход заново читает свежую выборку.

В панель добавлены 20 каналов 16 инвесторов и групп: YC RFS, a16z, Sequoia, Bessemer, GV,
General Catalyst, Khosla Ventures, Lux, DCVC, Breakthrough Energy, Lowercarbon, SOSV с HAX и
архивом IndieBio, AgFunder, BlueYard, Eclipse и Space Capital.
Проверенные публичные страницы обходятся существующими `url`/`urls`, ленты — `feed`.
Отрасль каждого канала указана в его записи конфига.

`genre=investment_thesis` обозначает курируемые тезисы, RFS и контекст портфеля;
`genre=investor_commentary` — новости и комментарии инвестора. Эти жанры допустимы только
у `feed`, `rss`, `url` и `urls`. Они не означают ни событие финансирования, ни научную
публикацию: заявленный интерес, исторический портфель и сообщение о раунде — разные факты.
Источник хранит `observed_at`; без явной даты издателя `date` остаётся пустой, а
`published_at` отсутствует. Такие записи доступны как контекст через явную выгрузку,
но не увеличивают помесячные счётчики. В покрытии они отмечены отдельным `undated`,
в статусе — `undated_records`.
Весь поток инвесторских лент сохраняется как контекст: отдельное извлечение подтверждённых
раундов из этих каналов не включено. IndieBio переименован в SOSV NY/SF в 2026 году;
его RSS отмечен как архив с исходными датами. Страницы действующих программ перечислены
в каталоге, но не собираются: их robots.txt содержит директиву `Crawl-delay` до `User-agent`,
которую строгий парсер отвергает. Действующая лента SOSV подключена отдельно.

Ещё 11 запросов Crossref выделяют отдельные бюджеты для финансовых технологий, связи,
полупроводников, робототехники, права, медиа, текстиля, спорта, туризма, детских сервисов и
музыки. Названия отраслей согласованы с
[каталогом Dealroom и исследовательских рубрик](../../frontend/src/shared/lib/researchTaxonomy.json).
`industry` здесь описывает направление отбора источника; это не проверенная классификация
каждой найденной работы. Общая панель — 299 источников и 197 доменов при пределе 320.

Остальное окружение: `DATA_DIR` (по умолчанию `/data`), `RENDER_URL` и `RENDER_TOKEN`,
`SOURCE_PROXY_URL`, `EPO_OPS_KEY` и `EPO_OPS_SECRET`, `ROSPATENT_API_KEY`. Веб-сборщику в Compose
задан предел контейнера 2 ГиБ и `GOMEMLIMIT=1600MiB`, иначе снимок доходит до OOM.

## Цикл сбора

Сервис собирает раз в 6 часов, `/app --once` делает один проход с пределом 90 минут. Файловая
блокировка `collection.lock` не даёт двум писателям работать с одним томом. Неизменяемые
страницы выпусков и месяцев кешируются атомарно, поэтому бюджет или обрыв продолжаются с
недостающих страниц. Закрытые месяцы кешируются насовсем, текущий перечитывается раз в сутки по
UTC. Неудачный проход оставляет прежний снимок.

В `DATA_DIR` лежат `snapshot.json` с полным манифестом происхождения и сырые ответы в
`raw/<sha256>`. Смена парсера или состава источников меняет отпечаток `source_set` и
пересобирает историю тем же путём, а не переименовывает старую.

## Источники: лимиты и капризы

### USPTO

- Популяция — выданные патенты США (utility, design, plant, reissue) за настроенную историю.
  52-недельный индекс Official Gazette даёт даты выпуска и ссылки; дата публикации берётся с
  обложки выпуска, противоречивая или устаревшая обложка оставляет окно неполным.
- USPTO Public Search работает через обычную анонимную сессию: ключ и учётная запись не нужны.
  Запросы — не чаще раза в 3 секунды, точный поиск `YYYYMMDD.PD.` в `USPAT` страницами по 500.
  Ранняя история режется на месяцы запросом `@PD>=YYYYMMDD<=YYYYMMDD`. Остаток добирается
  запросами не длиннее 40 номеров: публичный адрес отвергает длинные тела с OR.
- HTTP 429/503 сохраняет `Retry-After` в `patent-metadata-retry.json`. После 401 допускается
  одно обновление сессии. Только этот клиент ходит по HTTP/1; остальной трафик не меняется.
- Секционный полный текст (`GET /api/patents/highlight/{guid}`) анонимной сессии отдаётся
  меньшинству документов. Отказ записывается как `full_text_unavailable`, метаданные остаются.
- Номера, которые USPTO отозвал до выдачи, записываются как явно исключённые. Коды `E/E1` и
  `S/S1` — по [таблице kind-кодов USPTO](https://www.uspto.gov/patents/search/authority-files/uspto-kind-codes).
  Семейство — «USPTO Public Search Family ID», не INPADOC и не мировое семейство.

### EPO

- **European Publication Server** ([REST](https://data.epo.org/publication-server/rest/v1.2))
  работает без ключа. Fair use — 10 ГБ на IP за скользящие 7 суток; учёт байтов по дням ведётся в
  `ep-fairuse.json` и переживает перезапуск. Полный текст (claims, description) есть только у
  выданных B1/B2, аннотация — у A3. Остальные записываются с `full_text_unavailable`. Семейств
  сервер не отдаёт.
- **EPO OPS** включается ключом и секретом с developers.epo.org и `ops_documents > 0`. Токен
  живёт 20 минут. Темп задаёт `X-Throttling-Control`: пауза `60/N` секунд по значению для
  `search`, на `black` сбор останавливается. Бесплатная квота — 4 ГБ в неделю; при исчерпании
  OPS отвечает 403 с `X-Rejection-Reason`, и проход встаёт на курсоре. Поиск отдаёт не больше
  2000 результатов на запрос, остаток пишется в ограничения. Два последних месяца перечитываются
  каждый проход: ведомства доходят до DOCDB с задержкой. Семейства — DOCDB.

### Роспатент

Включается `ROSPATENT_API_KEY` из кабинета searchplatform.rospatent.gov.ru и `ru_documents > 0`.
Запрос — `POST /patsearch/v0.2/search`. Квот спецификация не называет, поэтому темп — раз в
секунду, а на первом отказе (401 — ключ, 429 — `Retry-After`) проход останавливается на курсоре.

### Китай

`cn-patents` обходит недельные страницы `/sitemap/` Google Patents и читает
`/patent/{номер}/zh`. Поиск Google запрещён в robots.txt и не используется, сессия CNIPA — тоже.
Карта сайта запаздывает, источник неполный: последняя неделя и курсор видны в покрытии. После
404/410 документ не запрашивается повторно 7 дней. Группируется только одна заявка, не мировое
семейство.

### Веб

- Панель доменов — единственный источник правды: адрес вне панели не запрашивается, редирект
  наружу отклоняется. Соединение открывается только к публичным адресам — loopback, частные
  сети, link-local (включая `169.254.169.254`), CGNAT и multicast отсекаются на самом
  соединении. Так закрыты и DNS, указывающий внутрь, и подмена адреса между проверкой и
  подключением.
- `SOURCE_PROXY_URL` (`http://`, `https://` или `socks5://`) пускает все запросы через прокси.
  Тогда соединение открывает прокси, и адрес сверяется с панелью перед каждым запросом и
  редиректом.
- robots.txt читается раз за проход на домен, для `*` и `rag-test-signalgraph`. Страницы за
  логином не собираются, учётные данные в URL отклоняются.
- Текст статьи извлекает `go-trafilatura`: вход до 8 MiB, до 50 000 узлов HTML, до 256 KiB
  текста. Блоки, которые домен повторяет больше чем на половине страниц прохода, удаляются с
  ограничением `boilerplate_removed`. Дата публикации — только из явных метаданных издателя.
- Страницу без основного текста один раз перечитывает изолированный браузер `page-renderer`
  (`RENDER_URL`). Код страницы работает только там. Рендерер ставит в своём сетевом пространстве
  фильтр: частные адреса запрещены, наружу — только TCP 80/443. Без nftables на хосте он не
  стартует. Такой текст помечен `method=javascript_render`. Проверка изоляции:
  `docker exec -i --user blessuser <renderer> node --input-type=module - <IP стенда в LAN> < infra/page-renderer/check.mjs`.

### arxiv-gateway

Сериализует обращения к `export.arxiv.org/api/query`: одно соединение и не меньше 3 секунд
между запросами. 429/503 соблюдает `Retry-After` и сохраняет паузу в
`DATA_DIR/arxiv/cooldown.json`, перезапуск её не сбрасывает. Если пауза длиннее 3 секунд, шлюз
сам отвечает 429 с `Retry-After`. Ответы по закрытым месяцам кешируются на 24 часа и отдаются
даже во время паузы, с заголовками `X-Radar-Cache` и `X-Source-Observed-At`. Текущий месяц из
кеша не подставляется.

## Внутренний API

- `GET /healthz` — процесс жив. `GET /readyz` — снимок не старше 72 часов.
- `GET /v1/status` — последнее наблюдение, следующий запуск, ошибки, `source_set`, счётчики и
  покрытие по источникам и месяцам. `pages` — первые 16 страниц, `pages_total` — все.
- `POST /v1/query` — фразы по проверенным заголовкам и тексту за непрерывные интервалы: до 200
  записей и нижняя граница счёта. Термины разделяются `|`, `*` в конце включает поиск по
  префиксу (`искусственн*`), русские слова сравниваются по основе. С `"titles": true` термин ищется
  только в заголовках, а у записи есть `excerpt` до 700 символов.
- `GET /v1/records?from=…&through=…&query=…&limit=…&cursor=…` — выгрузка для source-harvester;
  `query=*` — все записи. Курсор закреплён за упорядоченными id, ревизиями фактов и популяцией
  источника. Если популяция сменилась, ответ — 409.
  По умолчанию возвращаются только датированные записи. `include_undated=1` дополнительно
  включает контекст без даты публикации, наблюдавшийся в этом окне; поле `date` при этом
  не заполняется. Необязательный `genre=investment_thesis` или `genre=investor_commentary`
  ограничивает выдачу соответствующим жанром. Оба параметра допустимы только у веб-сборщика;
  неверный жанр или значение `include_undated`, отличное от `0`/`1`, возвращает 400.
  Харвестер явно включает этот режим только для `provider=web` и
  `work_type=investment_thesis`; существующие scope продолжают читать датированные записи.
  Ограниченный импорт описан в [README харвестера](../source-harvester/README.md#инвестиционные-материалы).

Счётчики тем — нижние границы. Неизвестный период — `null`, а не ноль.

## Проверка

```sh
go test -race ./...
golangci-lint run ./...
scripts/tools/data/check_source_parsers.sh   # из корня: живые запросы к источникам
TR_LIVE_SOURCES=1 TR_LIVE_INVESTORS=1 go test -run '^TestLiveInvestorSources$' -v
```

Скрипт сохраняет сырые байты, извлечённые записи и ответы выгрузки в
`artifacts/parser-verification/run-*`. Если поставщик недоступен, скрипт завершается с ошибкой:
429 не считается пустым успешным ответом. Рабочие документы и индексы скрипт не трогает.
