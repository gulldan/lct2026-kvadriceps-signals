# eval-service

Прогоняет размеченный набор вопросов через живой RAG API, сравнивает источники и ответы с
эталоном и публикует сводку в `POST /admin/metrics` (читается `GET /admin/metrics`).
Рядом, в [signalgraph/](signalgraph/PROTOCOL.md), — отдельный benchmark анализа трендов по
корпусу.

## Запуск

В Compose плановый прогон выключен (`EVAL_INTERVAL_SEC=0`); разовый запускает
`POST /admin/metrics/run` — он ставит ключ `rag:eval:trigger`, который воркер проверяет каждые
`EVAL_CHECK_INTERVAL_SEC`. Кнопки в интерфейсе нет. Локально из `ml-services/eval-service`
с `PYTHONPATH=../runtime`:

```bash
python3 evaluate.py          # сводка, код выхода 0
python3 evaluate.py --gate   # или EVAL_GATE=1
```

`--gate` возвращает 0 — пройдено, 1 — качество ниже порога, 2 — недоступен стенд или
испорчен набор. Пороги задаются `EVAL_MIN_<МЕТРИКА>` (например,
`EVAL_MIN_ANSWER_SIMILARITY`); они подобраны под синтетический набор, на котором поиск
держится около 1,0. Судья — модель из `VLLM_*`: без неё метрики судьи пустые, и gate
проваливается; пропустить их явно — `EVAL_SKIP_JUDGE=1`.

## Метрики

- Поиск: `hit@k`, `mrr`, `ndcg@k` (k — `EVAL_TOPK`, по умолчанию 5).
- Ответ, оценка судьи: `faithfulness`, `answer_relevance`, `context_relevance`,
  `answer_correctness`.
- Ответ, без судьи: `answer_similarity` — косинус F2LLM между ответом и эталоном.
- Задержка p50/p95/средняя — из Prometheus (`EVAL_PROM_URL`).

Вне gate и только в сводку:

- `EVAL_HYPOTHESES=1` — Фабрика гипотез по `dataset-hypotheses.jsonl`: полнота схемы,
  наличие контрдоказательств, отделение сильных гипотез от слабых. В Compose выключено:
  тратит вызовы генерации на каждом прогоне.
- `EVAL_DISCOVERY=1` — опубликованная доска гипотез discovery: проверяемость, привязка к
  источникам, связь тем, контрдоказательства, новизна, вклад по сравнению с кластерными
  гипотезами. Только читает доску, в Compose включено.

## Наборы данных

`dataset.jsonl` — вопросы для RAG, `dataset-hypotheses.jsonl` — KPI и ожидания для
гипотез. Коммитить только синтетические или очищенные наборы: без названий клиентов,
ключей, телефонов, внутренних адресов и секретов.
